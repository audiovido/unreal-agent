# Unreal Agent Vision

A fully local, autonomous Unreal Engine engineering agent.

The agent should be able to:
1. Understand an entire Unreal project.
2. Plan changes before execution.
3. Operate Unreal Engine through dedicated tools.
4. Write and modify C++.
5. Work with Blueprints and UMG.
6. Build gameplay systems.
7. Create and modify levels.
8. Manage assets.
9. Compile and inspect errors.
10. Test its own work.
11. Diagnose failures and retry safely.
12. Use local LLMs for reasoning and specialist tasks.
13. Maintain persistent memory about each Unreal project.
14. Keep logs and reversible change history.
15. Ask the user only when an action is destructive or genuinely ambiguous.
