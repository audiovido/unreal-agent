# Aivido Unreal Graduation Contract

Unreal work may not graduate from HTTP success, process exit code, build success, or file creation alone.

Final graduation requires live Unreal readback:
- bridge healthy
- live map present
- expected map match when declared
- actor-count gate
- evidence written
- bounded retry
- BLOCK after retry exhaustion

Verified runner: `tools/aivido_verified_mission.py`
